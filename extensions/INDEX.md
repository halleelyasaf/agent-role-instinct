# Original extensions

These are original methods, separate from the 283 upstream-adapted catalog roles. They are not entries in catalog.json and are not automatically imported into a website.

- [Task Role Coordinator](task-role-coordinator.md), `specialized/task-role-coordinator`: select relevant roles afresh for each task, create focused internal requests, and track recommendations through responses. Standalone guidance; not tested on a real task or enforced by a website.

The [extension manifest](manifest.json) records original provenance and reviewed file hashes. No upstream source or source hash is claimed. Catalog integration is a separate reviewed change.
